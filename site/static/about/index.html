About

Who, what and under which terms

I am Muhammad Adnan, an applied AI engineer. I built sld2quote in October 2026 as evidence for my application to the University of Salford and R&B Switchgear Knowledge Transfer Partnership, Artificial Intelligence and Machine Learning Engineer (KTP Associate), and this site is the link I share with the assessor, in my application and with the company.

Author and licence

Code and text: Muhammad Adnan. Licence: MIT, copyright 2026 Muhammad Adnan, so a company or a university can use any part of it without obligation. The repository is private at the time of writing and opens on request; the trained detector is in a private model repository on the Hugging Face Hub, published to the site at deployment time.

Third-party parts keep their own licences: the IEC 60617 symbol artwork in assets/symbols/ is from the QElectroTech elements library (CC BY 3.0), taken unchanged through the synergycodes single-line-diagram set; the detector is RT-DETR through the Hugging Face transformers library (Apache-2.0), fine-tuned from the published r18vd weights; the text reader is RapidOCR running the PP-OCR models (Apache-2.0). The 19 real drawings in the gallery are figures from United States federal manuals, public domain as works of the US government (17 U.S.C. 105), with each sheet's source recorded in the repository. Every source is listed on the References page.

Synthetic data, invented prices

Every drawing the system was trained and scored on is synthetic, drawn by its own generator, which also writes the answer key. The catalogue, the part numbers and the prices are invented and labelled as such on every quotation. The real drawings in the gallery are public-domain figures, shown unscored because they have no answer key yet. Nothing in this project comes from R&B Switchgear: no drawing, no part, no price. The company's problem is described only as its public job description states it.

Every number on this site is read from the evaluation files the code wrote, when the page loads; none is typed into a page. The full files are on the Evidence page.

AI assistance

I designed, researched and planned this project and its architecture, took every decision in it and reviewed every result. AI coding tools (Claude, by Anthropic) wrote code, tests and documents to my direction, which is what let one person build and measure it in days.

What that means in practice is on the Why me page: the decisions, the reviews and the acceptance tests were mine; the typing was not. I consider directing, reviewing and measuring AI-written code a core skill of the role this site is evidence for, and I say so rather than hide it.

This site

Plain HTML, CSS and JavaScript with no framework and no build step; one script serves every page. The pages were checked in headless Chrome at phone and laptop widths, in light and dark mode, with the keyboard alone, against the WCAG 2.2 targets for contrast, focus and target size. The server is a small FastAPI application on Google Cloud Run inside the free tier; it sleeps between visits, which is why the first run of a session waits about 20 seconds. A static copy of the samples and scorecards lives on a Hugging Face Space as the fallback.

Version 0.3.0, 19 October 2026. Problems met on the way are recorded in plain language on the Problems page.
