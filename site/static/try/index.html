One drawing, three steps

Choose a drawing and run it live: the server reads it stage by stage, each stage says what it is doing, which technology does it and what it found, and the results open with the drawing, the parts and the questions. The server sleeps between visits, so the first run waits about 20 seconds while it wakes.
